# 法律法规检索手机快捷应用 1.0.2

这是一个离线优先的 PWA（网页快捷应用），不是 APK 或 iPhone 安装包。首次通过 HTTPS 网页地址打开后，可添加到手机桌面；添加后会以接近 App 的独立窗口运行。

## 适用设备

- Android：Chrome、Edge、华为浏览器、360 浏览器等主流浏览器可使用；菜单通常叫“安装应用”或“添加到主屏幕”。
- HarmonyOS：使用系统浏览器或 Chromium 内核浏览器打开，选择“添加到桌面 / 添加到主屏幕”。
- iPhone / iPad：请用 Safari 打开，点“分享”→“添加到主屏幕”。
- 电脑：Chrome 和 Edge 也可安装为桌面应用，或直接用浏览器打开。

不同品牌手机的菜单名称不同，但检索、加密解锁和离线能力相同。必须从部署后的 HTTPS 网页地址打开；直接双击 `index.html` 只能浏览，不能安装或离线缓存。

## 页面内安装入口

密码页已提供“安装为独立应用”。在 Chrome、Edge 等支持 PWA 安装的浏览器中，点击后会直接弹出系统安装确认；请优先选择“安装应用”，而不是仅“添加快捷方式”。在 iPhone、部分 HarmonyOS 或第三方浏览器中，浏览器不允许网页自行完成安装，按钮会展示对应的“添加到主屏幕”步骤。真正安装成功后，桌面会出现“法规检索”图标，打开时不会显示浏览器地址栏；只创建网址快捷方式的浏览器则仍会显示网址，这是浏览器本身的限制。

手机首次输入正确口令后，会在本机解锁加密数据库。请保持页面打开并等待提示完成；首次在性能较低的设备上可能需要 5–20 秒。

## 记住口令与退出登录

密码页默认勾选“记住口令（仅此设备）”。成功进入一次后，下一次会自动解锁，不需要再次输入。口令只保存在该手机的当前浏览器中，不会上传；如需清除，请在检索页面顶部点击“退出登录”。清除浏览器数据、卸载浏览器或更换浏览器后，也需要重新输入。

## 首次发布（不需要新增付费服务器）

可以继续使用现有 GitHub Pages：在现有网页仓库中新建一个文件夹，例如 `mobile/`，将本目录全部文件上传到该文件夹。发布后使用类似下方的网址：

`https://liuxy0209.github.io/law-regulations-search/mobile/`

首次打开时请保持联网，等待页面提示“离线数据已准备好”。随后即使断网，也可继续打开和检索已经下载的数据。

## 更新制度数据

每次制度数据更新时：

1. 用最新数据重新生成加密版 `law_db.js`，替换本目录的同名文件。
2. 修改 `app-version.json` 中的 `version`、`dataVersion`、`updatedAt` 和说明。
3. 将 `sw.js` 中的 `CACHE_NAME` 版本号改成与 `app-version.json` 一样，例如 `law-search-mobile-1.0.1`。
4. 将全部改动上传到 GitHub Pages。

用户下次联网打开快捷应用时会看到“发现新版制度数据”，点击“立即更新”即可下载新版本；未更新前，旧数据仍能离线检索。

## 安全说明

制度数据包和页面均会下载到安装者手机的浏览器离线缓存中；访问口令只参与本机浏览器解密，页面不会记录或上传口令。由于 GitHub Pages 是公开静态托管，不适合放真正高度保密的原始资料；如以后需要账号权限、撤销访问或审计，应改为企业内部服务器方案。
